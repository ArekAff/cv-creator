# Source material

The rules in `method/` were distilled from the reading that belongs in this folder. Other people
wrote it and hold the copyright, so the files aren't published with this project. The tool doesn't
need them: everything an interview or a CV relies on is in `method/`. File names and line or page
references in `method/` refer to local copies.

- **The interview method:** Linderman, A., Baker, J. & Bosacker, S. C. (2011). *Surfacing and
  transferring expert knowledge: the sense-making interview.* Human Resource Development
  International, 14(3), 353–362 (`HRDIArticle.pdf`).
- **The CV rules:** the guide *A practical guide for tailoring your resume*
  (`guide-to-great-cv.txt`).
- **The tailoring playbooks:** web articles on tailoring a CV (`how-to-tailor-resume/`). Each
  `method/tailoring-*.md` file lists the ones it draws on.
